# Laboratorio Agente – Plan de Marketing

Herramienta interactiva diseñada para uso académico en el módulo **Mix de Marketing**.

## Contenido

- `index.html`: aplicación completa del laboratorio.
- `.nojekyll`: evita procesamiento innecesario de GitHub Pages.

## Publicar con GitHub Pages

1. Cree un repositorio nuevo en GitHub.
2. Suba `index.html` y `.nojekyll` a la raíz del repositorio.
3. Abra **Settings > Pages**.
4. En **Build and deployment**, seleccione:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/(root)**
5. Guarde los cambios.
6. GitHub generará la URL pública del laboratorio.

## Uso

El laboratorio guía al estudiante a través de 8 etapas:

1. Contexto y alcance
2. Análisis situacional
3. Objetivos
4. Mercado y cliente
5. Oferta de valor y Mix
6. Plan táctico
7. Presupuesto
8. Indicadores y cierre

La herramienta permite guardar el avance en el navegador, cargar un ejemplo guía, validar coherencia, generar un borrador del Plan de Marketing, descargarlo en Word e imprimirlo.
